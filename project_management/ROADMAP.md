## Detailed Phase Breakdown

### Phase 1: Research (Investigación)
- [ ] Analyze current mobile gaming market trends (hyper-casual, hybrid-casual, arcade, puzzle).
- [ ] Identify high-retention mechanics and psychological drivers.
- [ ] List common mistakes in modern mobile games (forced ads, pay-to-win, lacks depth).
- [ ] Find unexplored niches for simple-to-learn, hard-to-master games.
- [ ] Deliver: **Phase 1 Research Report** (`docs/phase_1_research.md`).

### Phase 2: Idea Generation (Generación de ideas)
- [ ] Brainstorm 30-50 unique, original mobile game concepts.
- [ ] Critique, filter, and merge concepts to find the absolute best fit.
- [ ] Deliver: **Phase 2 Ideation & Selection Document** (`docs/phase_2_ideas.md`).

### Phase 3: Validation (Validación)
- [ ] Answer key emotional, retention, and UX validation questions for the chosen idea.
- [ ] Refine the concept based on self-critique.
- [ ] Deliver: **Validation Report** (`docs/phase_3_validation.md`).

### Phase 4: Game Design Document (GDD)
- [ ] Detailed game systems, core/secondary loop, progression, monetization, and UX design.
- [ ] Deliver: **Master GDD** (`docs/GDD.md`).

### Phase 5: UX/UI Prototyping
- [ ] Map flow diagrams and build high-fidelity wireframes/screens.
- [ ] Deliver: **Navegation Flows & Assets** in `docs/ui_prototype/`.

### Phase 6: Art Direction
- [ ] Establish visual style, color palettes, sound guidelines, and effects.
- [ ] Deliver: **Art Direction Guide** (`docs/art_direction.md`).

### Phase 7: Technology & Engine Evaluation
- [ ] Compare engines (Unity, Godot, Defold, Flutter+Flame, HTML5/Phaser, etc.) based on game requirements.
- [ ] Deliver: **Technical Choice Decision Record**.

### Phase 8: Architecture
- [ ] Design a clean, modular code architecture, save systems, state machines, etc.
- [ ] Deliver: **Architecture Document** (`docs/architecture.md`).

### Phase 9: Vertical Slice
- [ ] Build a playable vertical slice representing the core game loop and feel.
- [ ] Iterate based on test playability and "juice" (animations, sounds, response).

### Phase 10: Full Development
- [ ] Code all modules, settings, shop, achievements, achievements, audio implementation.
- [ ] Produce production-grade code with clean architecture.

### Phase 11: QA & Optimization
- [ ] Rigorous testing for bugs, memory leaks, performance bottlenecks, and battery drain.
- [ ] Deliver: **QA Report & Release Build**.
